# Dudh-Sathi

A dairy business profit, sales, and customer ledger management tracker (दूध साथी).

## Features
- Daily sales and profit tracking
- Customer accounts and credit (उधारी) management
- Milk & dairy product catalog with pricing
- Daily ledger and collection tracking
- Supabase cloud synchronization

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
